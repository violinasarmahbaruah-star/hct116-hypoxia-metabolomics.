# LC-MS/MS Metabolomics: HCT-116 Response to Hypoxia and Anoxia
Dataset Reference: Metabolomics Workbench ST004105 (AN006807)

## Overview
A comparative metabolomics study examining 60 human HCT-116 colorectal carcinoma samples across Normoxia, Hypoxia, and Anoxia microenvironments spanning aqueous and organic extraction phases.

## Summary of Findings
- **Glutathione Collapse:** Reduced glutathione (GSH) drops >6.5x under oxygen deprivation (p < 0.0001).
- **MTA Accumulation:** 14.4x surge under anoxia indicating polyamine salvage pathway arrest.
- **Bioenergetic Depletion:** Severe collapse in active ATP/GTP pools paired with mitochondrial acylcarnitine export.
